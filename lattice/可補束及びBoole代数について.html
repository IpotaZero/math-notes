命題2
有界分配束において、補元は存在すれば一意である。
証明
DDDを有界分配束とする。
a,b,b′∈Da, b, b' \in Da,b,b′∈Dが以下を満たすとする。
a∨b=1a \vee b = 1a∨b=1
a∧b=0a \wedge b = 0a∧b=0
a∨b′=1a \vee b' = 1a∨b′=1
a∧b′=0a \wedge b' = 0a∧b′=0
このとき、a∨b=1a \vee b = 1a∨b=1の両辺にb′b'b′の交わりを取ると、
(a∨b)∧b′=b′(a \vee b) \wedge b' = b'(a∨b)∧b′=b′
分配性より
(a∧b′)∨(b∧b′)=b′(a \wedge b') \vee (b \wedge b') = b'(a∧b′)∨(b∧b′)=b′
変形すると
0∨(b∧b′)=b′0 \vee (b \wedge b') = b'0∨(b∧b′)=b′
b∧b′=b′b \wedge b' = b'b∧b′=b′
即ちb′≤bb' \le bb′≤bである。
同様にしてb≤b′b \le b'b≤b′も言えるからb=b′b = b'b=b′である。
注意
補元が一意に存在しても分配束とは言えない。(Huntington’s conjectureの反例)
定義3
有界束LLLにおいて、任意の元が少なくとも1つ補元を持つとき、LLLは可補束であるという。
例4
有限次元ベクトル空間VVVの部分空間全体の成す束K(V)K(V)K(V)は可補束である。
K(V)K(V)K(V)は一般には非分配的であり、補元も一意でない。
定義5
束LLLにおいて、LLLの任意の区間が可補束であるとき、LLLは相対可補束であるという。
注意
有界相対可補束は可補束である。
定義6
可補分配束をBoole代数と呼ぶ。
Boole代数において、任意の元aaaは唯一つ補元を持つから、それを¬a\neg a¬aと書く。

集合XXXに対し、そのべき集合P(X)\mathcal{P}(X)P(X)はBoole代数になる。
結びと交わりは和集合と共通部分。1=X,0=∅1 = X, 0 = \varnothing1=X,0=∅。補元は補集合で与えられる。

命題9
可補分配束 ⊊\subsetneq⊊ 可補モジュラー束
証明
分配束はモジュラー束であるから、可補分配束 ⊂\subset⊂ 可補モジュラー束である。
しかし、可補モジュラー束であるが可補分配束でない例がある。
例えばM3M_3M3​は可補モジュラー束であるが可補分配束でない。
