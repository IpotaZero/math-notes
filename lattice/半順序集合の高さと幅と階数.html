h1
高さ・幅・最小鎖分割数・最小反鎖分割数
定義1
半順序集合PPPの部分集合AAAが**反鎖 (antichain)**であるとは、以下を満たすことを言う。
∀x,y∈A,x≤y  ⟹  x=y\forall x, y \in A, x \le y \implies x = y∀x,y∈A,x≤y⟹x=y
(自身以外と順序関係を持たない)
定義2
半順序集合PPPの**高さ (height)**は、PPPの鎖の濃度の上限で定義される。
(上限が無限の場合は∞\infty∞とする。)
(※濃度-1で定義する流儀もある)
定義3
半順序集合PPPの**幅 (width)**は、PPPの反鎖の濃度の上限で定義される。
(上限が無限の場合は∞\infty∞とする。)
定義4
自然数mmmが半順序集合PPPの**最小鎖分割数**であるとは、以下を満たすことを言う。
PPPはmmm個の鎖による分割を持ち、mmm個未満の鎖による分割を持たない。
定義5
自然数mmmが半順序集合PPPの**最小反鎖分割数**であるとは、以下を満たすことを言う。
PPPはmmm個の反鎖による分割を持ち、mmm個未満の反鎖による分割を持たない。

命題6
半順序集合PPPの最小鎖分割数がmmmのとき、PPPの幅はmmm以下である。
証明
PPP の mmm 個の鎖による分割を P=⨆k=1mTkP = \bigsqcup_{k = 1}^m T_kP=⨆k=1m​Tk​ とする。
AAA を PPP の任意の反鎖とする。
反鎖の定義より、AAA の任意の異なる2元は互いに比較不能である。
したがって、同じ鎖 TkT_kTk​ が AAA の元を2つ以上含むことはできない。
（もし含めば、それらは鎖の定義から比較可能になってしまい矛盾する）
これより、各鎖 TkT_kTk​ (k=1,…,mk = 1, \dots, mk=1,…,m) は AAA の元を高々1つしか含まない。
したがって、反鎖 AAA の濃度は鎖の個数 mmm を超えることはできない。
\card{A} \le m
これが任意の反鎖 AAA について成り立つため、反鎖の濃度の上限として定義される PPP の幅もまた mmm 以下である。
命題7
半順序集合PPPの最小反鎖分割数がnnnのとき、PPPの高さはnnn以下である。
証明
PPPのnnn個の反鎖による分割をP=⨆k=1nAkP = \bigsqcup_{k = 1}^n A_kP=⨆k=1n​Ak​とする。
CCCをPPPの任意の鎖とする。
鎖の定義より、CCCの任意の異なる2元は互いに比較可能である。
したがって、同じ反鎖AkA_kAk​がCCCの元を2つ以上含むことはできない。
（もし含めば、それらは反鎖の定義から比較不能でなければならず、矛盾する）
これより、各反鎖AkA_kAk​ (k=1,…,nk = 1, \dots, nk=1,…,n) はCCCの元を高々1つしか含まない。
したがって、鎖CCCの濃度は、分割を構成する反鎖の個数nnnを超えることはできない。
\card{C} \le n
これが任意の鎖CCCについて成り立つため、鎖の濃度の上限であるPPP自身の高さもnnn以下である。

定義16
半順序集合PPPから鎖CCCへの関数ρ:P→C\rho: P \to Cρ:P→Cが**CCC-階数関数 (CCC-rank function)**であるとは、以下を満たすことを言う。
∀x,y∈P,x<y  ⟹  ρ(x)<ρ(y)\forall x, y \in P, x < y \implies \rho(x) < \rho(y)∀x,y∈P,x<y⟹ρ(x)<ρ(y)
∀x,y∈P,x≺y  ⟹  ρ(y)≺ρ(x)\forall x, y \in P, x \prec y \implies \rho(y) \prec \rho(x)∀x,y∈P,x≺y⟹ρ(y)≺ρ(x)
特にC=ZC = \ZC=Zのとき、単に**階数関数**と呼ぶ。

[4   ⟹  \implies⟹ 3]
条件4より、PPPのすべての極大鎖は等しい濃度 LLL を持つ。
任意の区間 [x,y][x, y][x,y] における2つの極大鎖 C,DC, DC,D を取る。
PPP は有界であるから、[0,x][0, x][0,x] の極大鎖 BBB と、[y,1][y, 1][y,1] の極大鎖 TTT が存在する。
これらを連結した C′=B∪C∪TC' = B \cup C \cup TC′=B∪C∪T および D′=B∪D∪TD' = B \cup D \cup TD′=B∪D∪T は、どちらも PPP 全体の極大鎖である。
ここで、PPP は鎖有限であるため、すべての極大鎖の濃度は自然数である。
したがって、鎖の濃度について以下の加法性が成り立つ：
\card{C'} = \card{B} + \card{C} + \card{T} - 2
\card{D'} = \card{B} + \card{D} + \card{T} - 2
条件4より、全体の濃度は等しく \card{C'} = \card{D'} = L である。
これらを代入して整理すると：
\card{C} = L - (\card{B} + \card{T}) + 2
\card{D} = L - (\card{B} + \card{T}) + 2
即ち \card{C} = \card{D}
よって、区間 [x,y][x, y][x,y] の任意の極大鎖の濃度は等しく、条件3が示された。
